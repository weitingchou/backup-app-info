Privacy policy

  • Only the owner uses this tool.
  • It asks Google only for the drive.file permission, so it can see and change only the files it created itself in the owner's Google Drive. It cannot see any other file.
  • Everything it stores is encrypted before it leaves the owner's computer.
  • It does not share, sell or send any data to anyone else, and it does not use any data for advertising.
  • The owner can remove its access at any time in their Google Account settings (Security → Third-party apps).

隱私權政策

  • 只有擁有者自己使用這個工具。
  • 它向 Google 只申請 drive.file 權限：只看得到、改得到它自己在擁有者 Google Drive 裡建立的檔，看不到其他任何檔。
  • 存放的內容在離開擁有者的電腦以前就已經加密。
  • 不分享、不出售、不傳送任何資料給其他人，也不用在廣告上。
  • 擁有者隨時可以在 Google 帳戶設定（安全性 → 第三方應用程式）移除它的存取權。
